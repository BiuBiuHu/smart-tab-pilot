# Chrome 网上应用店文案（中文）

建议类别：**效率工具 / Productivity**

## 简短介绍（≤132 字）

跨窗口精确 URL 去重 + 可学习任务导航图。仅侧边栏。可选设备端 Nano 或你自己的模型端点。

字数：50

## 详细介绍

Smart Tab Pilot 整理 Chrome 窗口里的标签，**不会按网站域名一锅炖**。

**精确 URL 去重（跨窗口）**
任意窗口若已打开同一 URL，会跳转到已有标签并关掉重复页。默认含 hash 精确匹配；可在设置中改为忽略 hash。

**任务导航图**
按真实导航关系聚成任务：标签树（opener）、引用页（referrer）、同窗口短时间相邻打开，以及可选的 URL 模式学习。页面语义只用来起名和精炼混杂簇，不会把同域名的不同工作硬并在一起。

**侧边栏**
点击工具栏图标（或 Ctrl+Shift+K / ⌘⇧K）打开整栏侧边栏：任务卡、拖拽合并、拆分、关闭本组、全部窗口 / 仅当前窗口、设置页。

**语言**
中文 / English。默认跟随浏览器，也可在设置中锁定。

**可选模型**
- 优先用设备端 Gemini Nano（Chrome Prompt API）给任务起名、判断是否同一项目。
- Nano 不可用时，可填写 OpenAI 兼容的 **Base URL、API Key、模型名**。该地址是**你自己配置的端点**，扩展不附带厂商后台。
- 没有模型时，分组仍走任务导航图，名称回退启发式。

**明确不做**
- 不因同域名而合并标签。
- 不持久化整页正文（只留标题 + 1–2 句摘要）。
- 不包含分析统计或崩溃遥测。

权限仅用于标签/标签组管理、侧栏 UI、页面短摘要，以及（可选）向你配置的模型地址发请求。数据流见隐私政策。

## 单一用途

整理浏览器标签：精确 URL 去重跳转，并在侧栏用任务导航图归组。
