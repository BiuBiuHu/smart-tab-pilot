# Smart Tab Pilot Markdown UI 原型

## 0. 版本历史

| 版本 | 日期 | 变更内容 | 变更原因 | 影响 |
|------|------|----------|----------|------|
| v0.1 | 2026-11-03 | Popup + 去重/分组行为草图 | MVP PRD 冻结 | awaiting-user-review；搜索区标注 post-MVP |
| v0.2 | 2026-11-03 | 主 UI 改为 Chrome side panel（占满侧栏） | 用户要求非弹窗 | `sidepanel/` + `sidePanel` 权限 |

## 1. 当前决策

- 当前 UI 结构：单一 **Chrome side panel**（无独立 options 页、无 action popup）；工具栏图标 / 快捷键入口
- 当前交互风格：中文短文案、卡片分区、开关 + 少量主按钮；状态用 badge；侧栏可拉宽
- 当前平台形态：Chrome MV3 **侧边栏**（`chrome.sidePanel`，占满浏览器侧栏高度）
- 页面类型：**工具页（C 端效率工具）**，非 B 类运营台
- 效率目标：打开侧边栏 ≤3 秒内完成「看懂 Nano 状态 / 开关去重与分组 / 一键分组」；去重主路径**无 UI**（后台静默完成）

## 2. 入口与信息架构

### 2.1 页面入口

- Chrome 工具栏扩展图标 → **side panel**（`openPanelOnActionClick`）
- （ahead-of-scope）`Ctrl+Shift+K` / `⌘⇧K` → 打开侧边栏；启用快速搜索后可聚焦搜索；**MVP 不宣传为验收项**

### 2.2 导航层级

- 单层侧边栏；无路由

### 2.3 信息分组（自上而下）

1. 标题区：产品名 + 副标题
2. ~~快速搜索（P1 / 现码已有，原型标注为非 MVP）~~
3. Gemini Nano 状态与下载
4. 功能开关（去重 / ignoreHash / 自动分组）
5. 自定义模型
6. 立即分组 + 结果反馈
7. 页脚降级提示

### 2.4 上下文与冗余控制

- 不在每行重复「当前窗口」——立即分组默认当前窗
- 列表决策字段：仅搜索结果需要（P1）
- 长内容：API Key 用 password 输入；不展示完整抽取正文

## 3. 页面清单

| 页面/弹窗 | 入口 | 目标用户 | 关键动作 | 权限 |
|-----------|------|----------|----------|------|
| Side Panel | 工具栏图标 / 快捷键 | 终端用户 | 配置、下载 Nano、立即分组 | 扩展已安装 + sidePanel |
| （无 UI）去重行为 | 用户开链/导航 | 终端用户 | 激活旧标签、关新标签 | tabs |
| （系统）标签组外观 | 分组成功后 | 终端用户 | 在 Chrome 标签条看到组名/颜色 | tabGroups |

## 4. 关键页面原型

### 4.1 Side Panel（MVP 可见）

```text
┌──────────────────────────────────────────┐
│ Smart Tab Pilot                          │
│ 精确去重 · 语义分组                      │
├──────────────────────────────────────────┤
│ [P1 非 MVP] 快速搜索                     │
│ ┌────────────────────────────┐ Ctrl⇧K  │
│ │ 搜索打开的标签 / 最近关闭…  │         │
│ └────────────────────────────┘         │
│ （结果列表：打开 / 已关闭）              │
│  ※ 产品范围：后续版本；勿作 MVP 验收   │
├──────────────────────────────────────────┤
│ Gemini Nano（内置 Prompt API）           │
│ 状态  [available|downloadable|…]         │
│ 说明文案…                                │
│ [ 下载 / 启用 Nano 模型 ]  ← 仅可下载时  │
├──────────────────────────────────────────┤
│ 功能开关                                 │
│ [✓] 精确 URL 去重跳转                    │
│ [ ] 去重时忽略 hash（默认关＝含 hash）   │
│ [✓] 自动语义分组                         │
├──────────────────────────────────────────┤
│ 自定义模型（OpenAI 兼容）                │
│ Nano 不可用时使用                        │
│ Base URL  [https://api.openai.com/v1]    │
│ API Key   [••••••••]                     │
│ 模型名    [gpt-4o-mini]                  │
│ [ 保存自定义模型 ]                       │
├──────────────────────────────────────────┤
│ [      立即分组当前窗口      ]           │
│ 结果：已分组 N 个 · 标签：… · 来源统计   │
├──────────────────────────────────────────┤
│ 页脚：当前将使用启发式 / 请配置模型…     │
└──────────────────────────────────────────┘
```

- 布局：纵向卡片；主按钮实心；次按钮描边
- 字段：见上
- 操作：切换即保存（开关）；自定义模型点保存；下载 Nano；立即分组
- 反馈：`action-result` aria-live；Nano badge 颜色区分可用/需下载/不可用

### 4.2 去重行为草图（无弹窗）

```text
用户点击链接 / 地址栏打开 URL A
        │
        ▼
  同窗口是否已有 URL A？
     │否│                │是│
     ▼                   ▼
  正常打开            激活已有标签
  继续分组流程        关闭新标签
                      （不进「最近关闭」）
```

### 4.3 分组行为草图

```text
load complete 且未去重关闭
        │
        ▼
  autoSemanticGroupEnabled?
     │否│              │是│
     ▼                 ▼
   结束            debounce ~800ms
                        │
                        ▼
              抽取文本快照（≤4k）
                        │
                        ▼
         Nano → Custom → Heuristic
                        │
                        ▼
              chrome.tabGroups 合并/创建
```

## 5. 状态与交互

### 5.1 加载、空态、错误态

- Nano 检测中：badge「检测中…」
- 立即分组无标签：结果提示 0
- 自定义保存失败：结果区错误文案
- 搜索无匹配（P1）：「无匹配结果」

### 5.2 表单校验和保存反馈

- Base URL / Key 允许空（表示不启用自定义）
- 保存成功：按钮旁或结果区短暂确认

### 5.3 权限差异和只读状态

- 无多角色；未授予 host 时抽取失败 → 启发式

### 5.4 预发/线上环境标识

- 不适用；Load unpacked 与商店包可用 version 字段区分（后续）

### 5.5 B 类运营效率检查

- 不适用（非 B 类）。工具效率：开关贴近说明；主 CTA 仅「立即分组」与「下载 Nano」。

## 6. 响应式与终端范围

- 仅桌面 Chrome 侧边栏；不适配移动
- 不要求暗色主题（可后续）
