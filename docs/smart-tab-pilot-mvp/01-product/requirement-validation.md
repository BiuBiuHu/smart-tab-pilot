## 2. 目标澄清

- 用户真正想完成的业务结果：（待确认）在标签过多时，快速定位已开/已关链接，避免重复开页，并按正文语义自动归组
- 主要用户/角色：重度 Chrome 用户 / 研发与研究场景（待确认）
- 核心操作闭环：打开页 → 精确去重跳转；浏览中 → 正文语义进组；快捷键 → 搜开/关标签并跳转或重开
- 工作单元和批量范围：单标签事件为主；「立即分组当前窗口」为窗口级批量
- 成本、时延和质量约束：优先本机 Nano；无 Nano 可提示下载或自备 OpenAI 兼容接口；抽取借鉴 page-agent 文本 DOM 以降本
- 返工/重试/回滚粒度：单标签重新分类；用户手动改组是否作为学习信号（待确认）
- 已向用户确认的结论：
  - 精确 URL 匹配才跳转
  - 按正文语义分组（非域名）
  - Nano 优先，可下载提示 + 自备模型
  - 开源 MIT
  - 参考 alibaba/page-agent 文本 DOM 降本
  - 快速查询含已打开与已关闭
  - 按 opc-skills 研发
- 仍需反问用户的问题：见弹窗 / 下一轮澄清
