最近更新：2026-11-03 · Chrome Manifest V3 扩展

我们是谁

Smart Tab Pilot 是开源浏览器扩展（MIT）。扩展没有自有云账号，也不附带运营后台。

扩展在你设备上存什么

只用 Chrome 存储接口：

  • 你选择的设置（去重、自动归组、快速搜索、窗口范围、界面语言）。
  • 可选的自定义模型字段：Base URL、API key、模型名（chrome.storage.sync）。
  • 标签短摘要：标题、路径/slug、1–2 句话 — 从不保存整页正文。
  • 导航图先验（URL 模式，不是整页文本）。
  • 本次会话的合并/拆分边，以及可选搜索用的最近关闭列表。

卸载扩展会从该配置中删除这些数据（仍受 Chrome 自身存储规则约束）。

会从页面读取什么

内容脚本可能从 http(s) 页面读取一份紧凑文本快照，好按主题给任务起名，而不是按网站品牌。内存中的摘录有上限，落盘前会再收成短摘要。

受限页面（chrome://、chrome-extension://、about: 等）会跳过。

网络：什么会离开这台设备

默认 / 未配置自定义模型

  • 若 Chrome Prompt API（LanguageModel / Gemini Nano）可用，短片段会发给设备端模型。这条路径不经过开发者运营的服务器。
  • 若没有 Nano，你也没配置自定义模型，归组只用本地启发式。不会上传页面正文。

自定义模型（仅在你配置时）

  • 你可以填写 OpenAI 兼容的 Base URL、API key 和模型名。
  • 扩展随后把简短的分类 / 是否同组提示 POST 到该地址（通常是 {base}/chat/completions），并带上你的密钥。
  • 目的地完全由你提供。作者收不到副本。
  • 不要指向不信任的主机；把密钥当秘密保管。

不会发送

  • 源码中没有分析统计、广告 ID、崩溃遥测或用量信标。
  • 不会自动调用写死的 Smart Tab Pilot 接口。

第三方

  • Google Chrome（标签 / 标签组 / 侧边栏 API；可选的设备端 Nano）。
  • 仅在你选择时：你填写为 Base URL 的那个地址的运营方。

儿童

本扩展是浏览器标签效率工具。不以儿童为对象，也不会在知情的情况下收集儿童个人信息。

变更

若数据处理方式发生变化（例如将来出现自有端点），必须先更新本政策与商店说明，再发布该版本。
